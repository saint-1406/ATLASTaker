# Апокриф — каталог общей библиотеки ATLAS

Cloudflare Worker (бесплатный тариф) с базой D1. Файлы хранятся на Google Диске тех, кто ими поделился.
Здесь только каталог: поиск, фильтры, жалобы. Скачивание идёт через Worker: он берёт публичный файл с Диска по API-ключу Google.

- `src/worker.js` — сервер (все адреса API перечислены в начале файла)
- `schema.sql` — таблицы базы
- `wrangler.toml` — настройки Worker
- тесты: `tests/apocrypha-worker.test.js` (запуск из корня репозитория: `node --test "tests/*.test.js"`)

Адрес каталога, который знает приложение: `https://atlastaker.en-safarov.workers.dev`
(`src/apocrypha/client.js`, CSP в `index.html` и `server/server.js`).

## Настройка (один раз)

Токены и ключи **никуда не вставлять в чат и не коммитить**: они живут только в настройках Cloudflare.

### 1. База D1
1. Cloudflare → **Storage & Databases → D1 SQL Database → Create**. Имя: `apocrypha`. Нажать **Create**.
2. На странице базы скопировать **Database ID** (это не секрет) и вписать его в `wrangler.toml` вместо `00000000-…`.
3. Там же открыть вкладку **Console**, вставить весь текст `schema.sql` и нажать **Execute**.

### 2. Сборка Worker из GitHub (Workers Builds)
Worker `atlastaker` уже подключён к репозиторию. В нём: **Settings → Build → Build configuration → Edit**:
- **Root directory**: `apocrypha`
- **Build command**: пусто
- **Deploy command**: `npx wrangler deploy`

Сборка запускается при каждом пуше в рабочую ветку (**Settings → Build → Branch control**; по умолчанию `main`).

### 3. Секреты Worker
**Settings → Variables and Secrets → Add**, тип **Secret**:
- `GOOGLE_API_KEY` — ключ Google (см. ниже)
- `IP_SALT` — любая длинная случайная строка (из неё получаются хеши адресов для лимитов и жалоб)

`GOOGLE_CLIENT_IDS` и `ADMIN_EMAIL` уже заданы в `wrangler.toml`.

### 4. Ключ Google
Google Cloud Console, проект ATLAS:
1. **APIs & Services → Credentials → Create credentials → API key**.
2. Открыть ключ: **API restrictions → Restrict key → Google Drive API**; **Application restrictions: None** (ключом пользуется только Worker). Сохранить.
3. Значение ключа положить в секрет `GOOGLE_API_KEY` (шаг 3).

И разрешение для приложения: **Google Auth Platform → Data access → Add or remove scopes** → отметить
`https://www.googleapis.com/auth/drive.file` → **Update → Save**.

Пока проект Google в режиме **Testing**, делиться файлами могут только тестовые пользователи. Смотреть и скачивать может любой.
Чтобы делиться могли все, нужно **Audience → Publish app**. У ATLAS только несекретные разрешения (`drive.appdata`, `drive.file`, `email`, `openid`), поэтому проверка от Google обычно не требуется.

## Как это работает

**Поделиться** (меню книги → «Поделиться в Апокриф»):
1. Приложение проверяет файл: формат по содержимому, не больше 50 МБ, SHA-256. Такой файл уже есть в каталоге — показывает существующий.
2. Язык берётся из данных книги, а если их нет — определяется по тексту.
3. Человек видит предупреждение и ставит галочку «у меня есть право делиться этим файлом».
4. Копия файла ложится в папку «ATLAS Apocrypha» на его Диске, и доступ к ней открывается по ссылке.
5. Worker проверяет:
   - что токен выдан приложению ATLAS;
   - что файл принадлежит этому человеку;
   - что размер и SHA-256 совпадают;
   - что файл открыт по ссылке;
   - что первые байты соответствуют формату.
6. Только после этого файл попадает в каталог. Владелец записывается как Drive permissionId, email не хранится.

**Скачать**: Worker берёт файл с Диска по ключу, приложение сверяет SHA-256 и кладёт файл в библиотеку.

**Жалобы**: «Пожаловаться» есть у каждого файла. Владелец приложения (`ADMIN_EMAIL`) видит жалобы в меню «⋯ → Жалобы» и может скрыть или вернуть файл.

**Снять с публикации**: автор убирает файл из каталога, копия с его Диска тоже удаляется. Владелец приложения может снять любой файл.

**Лимиты** (`LIMITS` в `worker.js`): запросы с одного адреса в час или 5 минут. Не больше 30 публикаций в день на человека.
