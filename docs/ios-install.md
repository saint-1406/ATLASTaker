# ATLAS на iPhone и iPad (.ipa)

Файл `ATLASTaker-<версия>-ios.ipa` не подписан: Apple разрешает запускать на iPhone только подписанные
приложения, поэтому его подписывает ваш Apple ID при установке. Бесплатный Apple ID подходит, но такая
подпись действует **7 дней**: потом приложение перестаёт открываться, пока его не переподпишут.
Заметки и книги при переподписи остаются — приложение ставится поверх.

Нужно: компьютер с Windows, кабель для iPhone и Apple ID (лучше отдельный, не основной).

## Установка через Sideloadly (Windows)

1. Поставьте **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store — Sideloadly нужны именно
   эти версии): apple.com/itunes и support.apple.com → iCloud для Windows.
2. Скачайте и поставьте **Sideloadly** с sideloadly.io.
3. Подключите iPhone кабелем, разблокируйте и нажмите «Доверять этому компьютеру».
4. Откройте Sideloadly, перетащите в окно файл `.ipa`, в поле «Apple account» введите Apple ID и
   нажмите **Start**. Пароль и код из SMS/уведомления Sideloadly спросит сам.
5. На iPhone (iOS 16 и новее): **Настройки → Конфиденциальность и безопасность → Режим разработчика** —
   включить, телефон перезагрузится, после загрузки подтвердить.
6. **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → «Доверять».
7. Открывайте ATLAS с экрана «Домой».

## Каждые 7 дней

- Проще всего: в Sideloadly при установке поставить галочку автоматического обновления
  (Advanced Options → *Automatically refresh*), а в iTunes включить синхронизацию iPhone по Wi‑Fi.
  Тогда Sideloadly переподписывает приложение сам, когда компьютер включён и телефон в той же сети.
- Или вручную: снова перетащить тот же `.ipa` в Sideloadly и нажать Start. Данные остаются.

Без компьютера: **SideStore** (sidestore.io) после разовой настройки переподписывает приложения прямо
на телефоне.

## Что работает и что нет (первая версия)

- Работают: заметки, библиотека и чтение, пометки, перевод онлайн (MyMemory), резервная копия
  («Скачать все заметки» открывает меню «Поделиться» → «Сохранить в Файлы»).
- Пока нет: сканера документов, перевода без интернета (модель Firefox), синхронизации с Google
  Диском, проверки обновлений внутри приложения — новую версию ставите тем же способом поверх.
- Данные хранятся в самом приложении. Если удалить приложение (а не переподписать), они пропадут —
  делайте резервные копии.
