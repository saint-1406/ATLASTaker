# Добро пожаловать в ATLAS

Это ваш блокнот: быстрый, тихий и без лишнего. Всё, что вы пишете, сохраняется само.

## Как это устроено

- Текст сохраняется через полсекунды после последней буквы. Кнопки «Сохранить» нет: внизу справа видно, что всё уже на диске.
- Заметки лежат обычными файлами .md, их можно открыть чем угодно. Перед каждым обновлением и раз в день ATLAS кладёт их копию в папку backups, а правки, которые не успели записаться, предложит вернуть при следующем запуске.
- Заголовок выбирается через тип абзаца на панели; разделы появляются в оглавлении.
- Скриншот вставляется прямо в заметку: Win+Shift+S, затем Ctrl+V. Картинку можно и перетащить в текст. Щелчок по ней — на весь экран.
- Ctrl+K открывает палитру: поиск по заметкам и все команды. Ctrl+, — настройки, в том числе язык (есть английский).
- Хочется атмосферы — включите оформление «Атлас»: заметка станет картой с рельефом, а заголовки — вершинами.

## Ввод и оформление

Выбирайте заголовки через тип абзаца, а жирный, курсив, подчёркивание и зачёркивание — кнопками панели. Активный формат подсвечен; пробел его сохраняет. В маркированном и нумерованном списках Enter после заполненного пункта добавляет следующий, а на пустом пункте завершает список или возвращает на уровень выше. В остальных блоках Enter начинает обычный абзац. Shift+Enter переносит строку внутри блока.

«Вставить → Аккордеон» создаёт сворачиваемый раздел. Измените название, нажмите Enter для содержимого, а затем «Абзац после блока», чтобы продолжить снаружи. Исходник Markdown — отдельный режим в меню заметки или настройках письма.

## Код

Для кода выберите «Вставить → Блок кода» или нажмите Ctrl+E. Shift+Enter добавляет строку кода, Enter — обычный абзац после блока. Подсветка языков и синтаксис /# доступны в режиме исходника:

```python
def outline(note: str) -> list[str]:
    """Заголовки заметки по порядку."""
    return [line.lstrip("# ") for line in note.splitlines() if line.startswith("#")]
```

```javascript
const sections = note.split('\n').filter((line) => line.startsWith('#'));
console.log(`Разделов: ${sections.length}`);
```

Обычная вставка не меняет тип текста. Для кода сначала выберите блок кода. В режиме исходника сохраняются прежние подсветка языков и умная вставка.

## Горячие клавиши

| Клавиши | Что делает |
| --- | --- |
| Ctrl+K | палитра: заметки и команды |
| Ctrl+Shift+P | только команды |
| Ctrl+N | новая заметка |
| Ctrl+, | настройки: язык, оформление, тема, акцент |
| Ctrl+. | режим фокуса |
| Ctrl+E | блок кода |
| Ctrl+Shift+M | комментарий к строке |
| Ctrl+F | поиск в заметке |
| Ctrl+Shift+B | скрыть список заметок |
| Ctrl+Shift+L | светлая / тёмная тема |
| Ctrl + плюс / минус | размер текста |
| Ctrl+клик | открыть ссылку |
| Ctrl+M | атлас заметок (в оформлении «Атлас») |
