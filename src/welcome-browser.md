# Добро пожаловать в ATLAS

Это браузерная версия блокнота: один файл, без установки. Всё, что вы пишете, сохраняется само.

## Где живут заметки

- Заметки хранятся в этом браузере. Если очистить его данные (история, файлы cookie и данные сайтов), заметки пропадут.
- Поэтому время от времени делайте копию: Ctrl+K → «Скачать все заметки». Получится архив .zip с файлами .md.
- Вернуть заметки из файлов: Ctrl+K → «Импорт .md».
- Если копии не было больше недели, ATLAS напомнит сам.

## Как это устроено

- Текст сохраняется через полсекунды после последней буквы. Кнопки «Сохранить» нет: внизу справа видно, что всё на месте.
- Строки с «# » в начале становятся разделами. Справа появляется оглавление, раздел с курсором подсвечен.
- Скриншот вставляется прямо в заметку: Win+Shift+S, затем Ctrl+V. Картинку можно и перетащить в текст. Щелчок по ней — на весь экран.
- Ctrl+K открывает палитру: поиск по заметкам и все команды. Ctrl+, — настройки внешнего вида.
- Хочется атмосферы — включите оформление «Атлас»: заметка станет картой с рельефом, а заголовки — вершинами.

## Код

Блок кода — три обратные кавычки и название языка. Подсветка включается сама:

```python
def outline(note: str) -> list[str]:
    """Заголовки заметки по порядку."""
    return [line.lstrip("# ") for line in note.splitlines() if line.startswith("#")]
```

Вставьте код из буфера — ATLAS сам обернёт его в блок и угадает язык. Не угадал — Ctrl+Z.

## Горячие клавиши

| Клавиши | Что делает |
| --- | --- |
| Ctrl+K | палитра: заметки и команды |
| Ctrl+N | новая заметка |
| Ctrl+, | настройки и резервная копия |
| Ctrl+. | режим фокуса |
| Ctrl+E | блок кода |
| Ctrl+Shift+M | комментарий к строке |
| Ctrl+F | поиск в заметке |
| Ctrl+Shift+L | светлая / тёмная тема |
