# Добро пожаловать в ATLAS

Это ATLAS для Android: заметки и библиотека для чтения в одном приложении. Всё, что вы пишете, сохраняется само.

## Где живут заметки

- Заметки и документы хранятся в приложении на этом телефоне. Если удалить приложение, они пропадут.
- Поэтому время от времени делайте копию: лупа вверху → «Скачать все заметки». Получится архив .zip с файлами .md, телефон спросит, куда его сохранить.
- Вернуть заметки из файлов: лупа → «Импорт .md».
- Если копии не было больше недели, ATLAS напомнит сам.

## Библиотека

- Кнопка с книгами вверху открывает библиотеку. В неё можно добавить PDF, EPUB, FB2, DOCX, Markdown, TXT и HTML.
- Ещё проще — открыть файл в любом приложении и выбрать «Открыть с помощью» или «Поделиться» → ATLAS.
- Книга открывается там, где вы остановились. A− и A+ меняют размер текста, ☰ — оглавление, «Назад» — обратно на полку.
- Выделите абзац и нажмите «В заметку» — он ляжет цитатой в заметку к этой книге.

## Как это устроено

- Текст сохраняется через полсекунды после последней буквы. Кнопки «Сохранить» нет: внизу видно, что всё на месте.
- Строки с «# » в начале становятся разделами.
- Кнопка слева вверху — список заметок, ＋ — новая заметка, лупа — поиск по заметкам и все команды.
- Настройки (кнопка с ползунками): тема, оформление «Атлас», размер текста и язык, есть английский.

## Код

Блок кода — наберите /# в начале строки: блок откроется, курсор окажется внутри. Ещё раз /# — выход из блока. Язык можно дописать после трёх кавычек, подсветка включится сама:

```python
def outline(note: str) -> list[str]:
    """Заголовки заметки по порядку."""
    return [line.lstrip("# ") for line in note.splitlines() if line.startswith("#")]
```
